# dsh-talk-map · 对话地图

[English](README.md) | 中文

DeepSeek Harness（dsh）的可视化对话地图插件：把你的每一个会话变成白板上的一张卡片。

> 源自 [Tasihi89/dsh-talk-map](https://github.com/Tasihi89/dsh-talk-map)（MIT）。本仓库是在其基础上大幅改造的分支：槽位布局、可缩放工作区、溢出抽屉、避让连线的路由都是在这里新增或重写的。

![工作区分组、置顶卡片与状态灯](https://raw.githubusercontent.com/Da0Mine/dsh-talk-map/main/docs/screenshots/workspaces-and-pins.png)

![卡片之间的连线，以及运行中 / 等你回复 / 待查看的指示灯](https://raw.githubusercontent.com/Da0Mine/dsh-talk-map/main/docs/screenshots/cards-and-links.png)

- **内置回收站**：地图和原生会话列表共用删除入口，删除前确认，可单条或批量还原、永久删除。原生列表支持右键打开三个点菜单。删除分组只处理该地图分组中的会话；普通分叉对话独立保留。rc.5 支持安全释放已打开的空闲会话后删除；运行中的会话需确认停止，最多等待 15 秒。回收站显示日志、缓存、附件和回收站占用，可按大小排序，永久删除前显示预计释放空间。首次升级后正常重启一次，以启用原生句柄追踪。
- **空间记忆代替脑内记忆**：卡片自由摆放 + 网格吸附，位置永远不会被自动打乱——你记得「那个对话在左下角」，它就一直在左下角。为 ADHD 用户设计，对所有人有效。
- **工作区是收纳盒**：分组会在不覆盖邻框的前提下自动扩展，默认最多 6 个位置；超过时最后一格显示折叠数量（例如 7 个会话显示 5 张卡片和「+2」），点开是抽屉。置顶卡片排在最前。手动缩放会切换为手动尺寸，右键分组可恢复自动尺寸；尺寸模式保存在当前浏览器。
- **归档可辨认**：归档会话保留地图位置和连线，卡片显示「已归档」，分组和折叠格显示归档数量；右键可取消归档或删除，取消归档后即可打开。
- **双击即聊**：双击白板空白处，就地新建一个会话，卡片出生在你点的位置。
- **连线分叉**：从一张卡的接口拉一根线到空白处，预览（可编辑）将要注入的上下文摘要，确认后开一个「带着旧对话记忆」的新会话。
- **卡片正面 = 恢复现场**：标题、你最后说的那句话、相对时间，以及状态灯（运行中 / 已完成 / 待查看 / 等你回复 / 已中断）。回来扫一眼就知道该干嘛。
- **连线的含义**：上下文已经同步过去的线自动隐去；落后了的线是带箭头的虚线；分叉血缘始终画出来。线会自动选面，两张卡贴太近时绕到上下边走，不会挤成一截看不见的短墩。
- **按需摘要**：三字段摘要（概要 / 关键结论 / 下一步）用你部署里的默认模型生成，卡片上的 ⟳ 可手动重生成。
- **中英双语界面**：地图顶栏那颗药丸按钮循环切换 自动 → 中文 → English，「自动」跟随 dsh 本身的语言，选择会记住。

- **状态栏**：地图左侧可收起的条，只列当前有状态灯的卡片（运行中 / 等你回复 / 待查看 / 异常终止）。单击或按 Enter / 空格打开对应会话，拖动可排序；状态变化的卡片跳到最上面，状态消失后自动退出。开合状态会记住，展开时左下角地图控件自动避让。

## 安装

```sh
# npm（推荐）
dsh plugin add dsh-talk-map

# 或直接从 GitHub 装——构建产物已随仓库提交，免构建
dsh plugin add github:Da0Mine/dsh-talk-map
```

重启 `dsh web`，侧栏底部出现地图按钮。

## 用法

| 操作 | 效果 |
|---|---|
| 侧栏地图按钮 / Esc | 打开或收起地图 |
| 拖卡片 | 摆放（16px 网格吸附，会保存） |
| 双击空白处 | 在那里新建会话并进入 |
| 双击卡片 | 打开那个会话 |
| 从卡片接口拖到空白处 | 预览注入内容 → 分叉出新会话 |
| 点堆叠格 | 打开抽屉，列出被折叠的会话 |
| 卡片上的 ⟳ | 重新生成摘要 |
| 右键卡片 / 连线 / 工作区 | 置顶、重命名、标为未读、查看摘要、归档、删除、推送开关、删除连线 |
| 顶栏语言药丸 | 循环 自动 → 中文 → English |

## 数据放在哪

- 画布数据（位置、连线、摘要）：`$DSH_HOME/storages/talk_map.json`，走 dsh 官方 storage-domain，原子写入。
- 删除会话时，把经验证的会话及子代理日志、恢复元数据放入 `$DSH_HOME/talk-map-trash/entries/`；还原可恢复，永久删除不可恢复。项目源码、生成文档及附件不会随会话删除。大小为文件逻辑大小，不代表整个 DSH 安装或文件系统实际释放量。
- 摘要走 dsh 本地 LLM 通道使用你配置的默认模型，没有其他外部请求。

## 兼容性

会话生命周期适配针对 DeepSeek Harness `0.2.1-rc.5`，使用实际 AgentLoop、SessionStore 和 JSONL/Zstd 组件验证。缺少安全释放句柄时仅拒绝该驻留会话；外部进程写租约仍会阻止删除。结构契约在 `src/client/dsh.ts` 与 `src/host/dsh-host.ts`，升级时从这两处入手。

升级测试包时，请先完全退出 DSH（包括托盘后台），安装后重新启动。普通删除兼容旧请求格式；“停止并删除”会先检查后端能力，版本不匹配时提示重启，不发送停止或删除请求。

删除成功后直接更新会话列表和地图，不弹出数量提示；需要恢复时在回收站还原，还原后自动刷新原生会话列表和地图，无需重载页面。删除失败仍会提示。其他底部提示在 5 秒后自动收起，鼠标悬停或键盘聚焦时暂停；确认对话框不会自动关闭。

# 开发 checkout 不自动安装；发布验收使用 Git 安装流程
